
# TuitionMate AI — Privacy & Safety Rules

## Demo Data
- Use fictional customers only.
- Do not store real children's information.
- Never commit passwords or API keys to GitHub.

## Data Collection
- Collect only information needed for enquiries.
- Do not request medical diagnoses or IC numbers.
- Explain why personal information is collected.
- Obtain appropriate consent before storing data.

## Data Security
- Restrict access to customer records.
- Use HTTPS for any public deployment.
- Protect API endpoints with authentication.
- Avoid logging sensitive request details.

## Data Retention
- Keep data only as long as needed.
- Define a deletion process before launch.

## AI Behaviour
- Only provide verified business information.
- Never invent prices, refunds or guarantees.
- Escalate sensitive and uncertain questions.
- Allow customers to request human assistance.

## Current Project Status
DEMO ONLY — No real customer data.
No public deployment yet.
