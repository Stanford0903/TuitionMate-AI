
# TuitionMate AI — Product Requirements

## Target Customer
Small tuition centres in Malaysia.

## Main Problem
Staff spend time answering repetitive questions
about classes, schedules, fees, and registration.

## MVP Features
1. Receive customer enquiries.
2. Answer questions using an approved FAQ.
3. Never invent unavailable information.
4. Hand unknown questions to a human.
5. Return a structured JSON response.

## Not Included Yet
- Real WhatsApp integration
- Online payments
- AI-generated study advice
- Real student personal information

## Success Criteria
- Correctly answer at least 16 of 20
  approved FAQ test questions.
- Unknown questions trigger human handoff.
- Invalid requests are rejected safely.
